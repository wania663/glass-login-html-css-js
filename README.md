# 🧊 Glass Login

A glassmorphism login card built with pure **HTML, CSS and JavaScript**. No libraries.

**Part 4/10** of my HTML CSS JS Series 🚀

## ✨ Features
- Frosted glass card with `backdrop-filter: blur`
- Floating blurred light orbs behind the glass
- Glowing input focus and button hover
- Show / hide password toggle
- Validation with shake animation
- "Logging in..." then "Welcome ✓" success state

## 🛠️ Tech Stack
HTML5, CSS3 (glassmorphism, animations), Vanilla JavaScript

## ▶️ How to Run
1. Download or clone this repo
2. Open `index.html` in your browser
